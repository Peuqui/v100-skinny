Triton 3.6.0 plus the 24 commits of branch sm7x-tensor-cores, at commit a89775cf52: tl.dot lowers to mma.m8n8k4 on Volta (sm_70) and to mma.m16n8k8 on Turing (sm_75) instead of FMA. The changes are in the TritonGPU dialect and the NVIDIA backend; on other architectures the build compiles like Triton 3.6.0. Shown upstream in https://github.com/triton-lang/triton/discussions/12517.

Install in place of triton 3.6.0:
uv pip install "https://github.com/Peuqui/triton/releases/download/v3.6.0-sm7x.a89775cf52/triton-3.6.0+sm7x.a89775cf52-cp312-cp312-manylinux_2_27_x86_64.manylinux_2_28_x86_64.whl"
python -c "import triton; print(triton.__version__)" then prints 3.6.0+sm7x.a89775cf52; uv pip install triton==3.6.0 goes back to stock Triton.
